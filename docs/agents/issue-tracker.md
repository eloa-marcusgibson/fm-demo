# Issue tracker

GitHub Issues at eloa-marcusgibson/fm-demo, accessed via the account-aware gh wrapper
(GH_ACCOUNT=eloa-marcusgibson). Triage label vocabulary lives in triage-labels.md.
State machine: needs-triage -> needs-info | ready-for-agent | ready-for-human | wontfix.
ready-for-agent means an agent brief comment exists and a crew may claim it.
Claims are stamped with in-progress before any spawn.
PRs are not a triage request surface (captain-filed work only).
